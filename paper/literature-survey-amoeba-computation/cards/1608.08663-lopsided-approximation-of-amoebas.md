## 计算对象
1. `amoeba` `A(f) = Log|Var(f)| ⊆ R^n`（f Laurent 多项式）；`unlog amoeba` `U(f) = |Var(f)|`（实半代数集）。
2. `lopsided amoeba` `L(f) := {Log|v| : f 在该点不 lopsided}`（Def 1.3：lopsided = 存在一项的模 > 其余项模之和，式 1.3）。关键包含关系：`A(f) ⊆ L(f)`，且一般 `A(f) ≠ L(f)`。
3. 实际计算的对象是**循环结式** `CycRes(f;r) = ∏_{k1=0}^{r-1}…∏_{kn=0}^{r-1} f(e^{2πi k1/r}z1,…,e^{2πi kn/r}zn)`（式 1.4），它也是 Laurent 多项式；近似 = 在给定点判定 `CycRes(f;2^k)` 是否 lopsided。
4. 输出语义（Problem 1.2，**非成员证书**）：证书成立 ⇒ `Log|v| ∉ A(f)`；并由 order map 给出该点所在补集分支。
5. **Log 原像的逼近**（§6）：用半代数集序列逼近 unlog amoeba `U(f)`（Theorem 6.1 + Algorithm 6.2）。

## 输入假设
- Algorithm 3.4 / 4.1 / 6.2 输入：`f ∈ Q[√−1][x]`（n 变量、次数 d）；4.1 另需区间端点 `s,t`、网格步长 `ℓ`、层级 `k`；6.2 另需 `ε > 0`。**系数必须是有理复数（精确算术）**。§7.1 说明实现细节：在 Singular 中用带参数 `I`（极小多项式 `I^2+1`）的有理环来模拟复数。
- 网格：`G := [s,t]^n ∩ (ℓ·Z)^n ⊆ Q^n`（§4），ℓ 取得足够小使 `[s,t]^n` 中任一 ε 球至少含一个网格点。若想找全补集分支，还需 ε 足够小 —— 但 §4 明说 **"there is currently no explicit expression describing how small ε should be chosen"**。
- §1–§4 未要求 f 非退化、无环或 Newton 多面体的特殊条件；对 Newton 多面体的唯一依赖是误差界中的次数 d（Remark 2.4），以及 §6 中 `M := New(f) ∩ Z^n`（若 supp(f) 是 circuit，则 order map 的像至多等于 supp(f)）。

## 算法步骤
### A. Purbhoo 骨架（§1、§2.2、§4）
1. 给定 ε>0，按 Remark 2.4 选层级 k（取 r = 2^k），满足 `rε ≥ (n−1) log r + log((n+3) 2^{n+1} d)`；等价 `2^k/k ≥ C(n,d)/ε`，`C(n,d) = (n−1)log 2 + log((n+3) 2^{n+1} d)`。
2. 造网格 G。
3. 对每个网格点 p，依次用 `g_j := CycRes(f; 2^j)`（j=1..k）测 lopsided；一旦某层 lopsided 就停（记下该层），否则 j+1；若 k 层都不 lopsided，则该点**不被认证**。
4. 认证点：`Log|p| ∉ A(f)`；再由主导项求 order（Theorem 2.5：若 g lopsided 且主导项 `|b_{α'} z^{α'}|`，则 `ord(Log|v|)·r^n = α'`）；对原始 f 则有 `ord(Log|v|) = α'`。
5. lopsided 判定工具（Lemma 2.6，三角不等式）：f 在 `Log|z|` 处不 lopsided ⟺ 存在 `θ∈(S¹)^d` 使 `∑_j b_j e^{θ_j√−1} z^{α(j)} = 0`。
6. 收敛（Theorem 2.3，Purbhoo Thm 1 "rough version"）：`r→∞` 时 `L(CycRes(f;r))` 一致收敛到 `A(f)`；更精确地 ∀ε>0 ∃N，使 r>N 时 `L(CycRes(f;r)) ⊆ A(f) 的 ε 邻域`。

### B. 循环结式如何替换一般结式（§3，核心贡献）
- 定义式 (1.4) 把 CycRes 写成逐变量一般结式 `Res_{u_n}(…Res_{u_1}(f(u_1 z_1,…,u_n z_n), u_1^r−1)…, u_n^r−1)`，这是瓶颈（CAS 通用结式无法利用 `u_i^r−1` 的稀疏性）。
- **Lemma 3.1**：∃ 次数 δ=deg g 的一元 h 使 `Res_u(g(zu), u^r−1) = h(z^r)`，其中 `h(z) = b^r ∏_{ℓ=1}^{δ}(z − ξ_ℓ^r)`。
- **Lemma 3.2**：`Res_u(g(zu), u^{2^k}+1) = h(−z^{2^k})`。
- **Lemma 3.3（倍增恒等式）**：`Res_u(g(zu), u^{2^{k+1}}−1) = Res_u(g(zu), u^{2^k}−1) · Res_u(g(zu), u^{2^k}+1)`。
- **Algorithm 3.4（快速循环结式）**：`CycResult := f`；`for j=1..n: for l=1..k:` `Multiplier := CycResult`，把 Multiplier 中"第 j 个指数不被 2^l 整除"的项**全部变号**，然后 `CycResult := CycResult · Multiplier`；返回 `CycResult = CycRes(f; 2^k)`。
  ⇒ 每翻倍一次只做"符号翻转 + 多项式乘法"，**不需要算任何结式**（分治/倍增，类比 Cooley–Tukey；正确性来自 Lemma 3.2+3.3）。

### C. Algorithm 4.1（用循环结式近似 amoeba，§4 逐字）
```
1: Input: f ∈ Q[√−1][x]，网格起止点 s,t，步长 ℓ，k ∈ N
2: Output: 网格点列表 + 每个点是否在 A(f) 的 ε 邻域内的 bit（若适用，再给补集分支的 order）
4: 造网格 G := [s,t]^n ∩ (ℓ·Z)^n
5: /* 用 Algorithm 3.4 计算 j=1,…,k 的 2^j 阶循环结式 */
6: for j=1 to k do
8:    g_j := CycResult(f, 2^j)
9: end for
11: L := [ ]
13: for every p in G do
14:    IsLopsided := false
15:    j := 1
16:    while IsLopsided = false and j ≤ k do
17:       if g_j is lopsided at p then
18:          IsLopsided := true
19:       else
20:          j := j+1
21:       end if
22:    end while
23:    if IsLopsided = true then
25:       α := (g_j 在 p 处主导项的指数) 除以 2^j       ← 原文如此
26:       Adjoin (p, 0, α) to L
27:    else
28:       Adjoin (p, 1, NaN) to L
29:    end if
30: end for
31: return L
```
- 正确性：由 Algorithm 3.4 + Theorem 2.5。
- §4 补充：由 L 可进一步得到**含于 amoeba 补集的多面体**集合——补集分支是凸的，且 order 为 α 的分支的 recession cone 等于 α 在 New(f) 中的法锥 [PT05]。
- ⚠ 观察到的内部不一致（如实记录，未擅自裁定）：Theorem 2.5 的换算是 `ord·r^n = α'`（r = 2^j 时即除以 `r^n = 2^{jn}`），而 **Algorithm 4.1 第 25 行写的是"除以 2^j"**；对 n=2 二者不同（2^j vs 4^j）。§7 的例子没有直接展示 order 数值，无法据以判定哪一处为准。

### D. Algorithm 6.2（半代数逼近 unlog amoeba，§6 逐字）
```
1: Input: f ∈ Q[√−1][x]，ε > 0
2: Output: U(f) 的半代数集逼近
3: 按 Remark 2.4 选足够大的 r ∈ N（相对 ε）
5: M := New(f) ∩ Z^n
7: g := 0（零多项式）
9: for b_α x^α term in CycRes(f;r) do
10:    g := g + |b_α| x^α            /* 取各项绝对值之和 */
11: end for
13: for α/r^n ∈ M do
14:    g(α) := g − 2·|b_α| x^α        /* 由"某项不主导"构造 */
15: end for
17: L := ⋃_{j=1}^{n}{x_j ≥ 0} ∪ ⋃_{α/r^n ∈ M}{g(α)}
18: return L
```
- **Theorem 6.1**：`∂L(CycRes(f;r)) → ∂A(f)`（r→∞，意义同 Theorem 2.3）。并且若 `R^n \ A(f) = ⋃_j E_{α(j)}(f)` 且 r 足够大，则 `U(f)` 落在下面半代数集的 ε 邻域内：对每个分支 α(j)，
  `∑_{β ∈ A(r)∖{r^n·α(j)}} |b_{r,β}| x^β ≥ |b_{r, r^n·α(j)}| · x^{r^n·α(j)}`，且 `x_1,…,x_n ≥ 0`
  （即"CycRes(f;r) 的每一项都不占优"这组不等式；A(r) 是 CycRes(f;r) 的支撑集）。
- 证明要点：r 足够大时 `A(f)` 补集的分支与 `L(CycRes(f;r))` 补集的分支一一对应；order 为 `α'` 的分支对应 `L(CycRes(f;r))` 中 order 为 `α'·r^n` 的分支（用到 Theorem 5.2，§5 未逐字读）。

## 精度控制
- 显式误差-层级界（Remark 2.4，引 Purbhoo Thm 1）逐字："if r is chosen such that `rε ≥ (n−1) log r + log((n+3)2^{n+1}d)`, then it holds that `CycRes(f,r)` is lopsided at the point `Log|v|`"；并给出 r=2^k 时只需 `2^k/k ≥ C(n,d)/ε`。整数 N 只依赖 ε 与 f 的 Newton 多面体/次数，且"can be computed explicitly from this data"。
- **证书是单侧的（外部/超集方向）**：`A(f) ⊆ L(f)`，故 lopsided ⇒ 点必不在 `A(f)`。因此 lopsided 近似是 amoeba 的**超集**（不是子集）；Theorem 2.3 保证 r 足够大后多出的区域缩进 ε 邻域。落在 ε 邻域内或 amoeba 内部的点**无法判定**（§1–§4 没有"点在 amoeba 内"的证书；§7.3 的实践做法是"若到第 k 层都没找到证书，就**假定**该点在 amoeba 里"）。
- 网格侧：ℓ 要小到"任一 ε 球含一个网格点"；但**论文明确承认没有 ε 的显式下界表达式**（§4："there is currently no explicit expression describing how small ε should be chosen"），实践中先选网格再反推 ε。
- 另一个经验性精度问题（§7.4）：半代数逼近**并不单调改善**——Figure 2 中 level 2 在某些区域比 level 3 更接近；作者称"does not seem to be a plotting artifact, and raises theoretical questions on the nature of the convergence of this approximation"。

## 复杂度与规模
- §3 复杂度分析（严格分析在 n=1，多元为"逐变量迭代一元情形"）：每一步 CycResult 至多 `d+1` 项；"每隔一项乘 −1"需 `⌊d/2⌋` 次算术运算；两个一元 d 次多项式相乘 `2d²+2d+1`（BPR03 Alg 8.3）；共 k 次 ⇒ 总代价 `< k(d/2+2d²+2d+1) = k(2d²+5d/2+1)`，即 **O(k d²)**。
- 对比（Remark 3.5）：最快通用结式算法 signed subresultant 为 `O(d₁d₂)`；此处 `d₁=d`、`d₂=2^k` ⇒ **O(d·2^k)**。结论逐字："Overall, it reduces the runtime from exponential to polynomial in one variable and from double to single exponential in arbitrary many variables."
- 但对象本身指数膨胀（§1 逐字点名）：CycRes(f;r) 的**度与项数随 r 指数增长**。Table 1（f = z1³+z1z2+z2³+1，r = 2^k）：
  | r | 2 | 4 | 8 | 16 | 32 | 64 |
  |---|---|---|---|---|---|---|
  | number of terms | 10 | 31 | 109 | 409 | 1585 | 6241 |
  | degree | 12 | 48 | 192 | 786 | 3072 | 12288 |
  | coefficient magnitude | 9 | 860 | >10¹² | >10⁵¹ | 10²⁰⁴ | 10⁸¹¹ |
- Hillar–Levine 的线性递推法（阶 `2^{deg g}`）可算全部循环结式，但"in general slower than our method"。

## 失效模式/限制
1. **外逼近/超集**：`A(f) ⊆ L(f)`，一般严格包含；只给"点在 amoeba 外"的证书。未认证点只能"假定在内"（§7.3 的实现策略），不是证明。
2. **精度渐近且无显式 ε 下界**：ε 决定 k（`2^k/k ≳ C(n,d)/ε`），而 k↑ ⇒ CycRes 度/项数指数增长（§1、Table 1）；§4 明确说没有"ε 该多小"的显式表达式（若要保证找到全部补集分支）。
3. **精确算术要求**：输入在 `Q[√−1]` 上；实现用 I²+1 模拟复数。浮点/超越系数会破坏不等式证书的可靠性（此推断依据输入假设与 Def 1.3，原文未讨论数值鲁棒性），对非厄米模型中是实打实的障碍。
4. **对象膨胀**：Table 1 显示同一 4 项 3 次二变量多项式在 r=64 时已有 6241 项、次数 12288、系数 >10⁸¹¹；虽然乘法便宜，但多项式本身很快变得无法存储/处理。
5. **收敛不单调**（§7.4 明说）：level 2 的逼近在某些区域优于 level 3，作者认为不是画图假象并提出理论问题。
6. **复杂度分析只在 n=1 严格给出**；多元按逐变量迭代一元情形处理。
7. **Algorithm 4.1 与 Theorem 2.5 的换算因子不一致**（÷2^j vs ÷r^n，见上），影响 order 的读取；原文未澄清。
8. §5 未读，无法确认几何那节是否附带额外条件（例如对 lopsided amoeba 边界与线性 amoeba 的对应）。

## 对 2 变量 amoeba 的适用性
- 算法对任意 n 表述，且 §7 的全部算例都是 2 变量（f1、f2）与 3 变量（f3）：**2 变量是本文实际跑通的主要情形**。
- n=2 时误差界为 `rε ≥ log r + log(40 d)`（由 `(n−1)log r + log((n+3)2^{n+1}d)` 代入 n=2 得，我的代数换算）；网格为 R² 上的 ℓZ² 格点。
- 输出形态：**网格点的外部判定 + 每个认证点的补集分支 order**（还可由此得到含于补集的多面体），**不是**边界曲线；要轮廓需网格细分/边界追踪，或走 §6 的半代数路线（Algorithm 6.2 给的是 x ≥ 0 象限内的半代数不等式组，`x_j = |z_j|`，正是"Log 原像"）。
- 实测规模参考：2 变量、3 次、4 项的多项式，k=4 的网格实验（81×81）是顺畅的；单点判定可到 level 6（28 s，对比通用结式 33 h）。

## 迁移到非厄米 2D GBZ 的可行性与障碍
- **可行**：对象与需求精确对上——2 变量 Laurent 多项式（`f(E,β) = det[E − h(β)]`），而 GBZ 判定经常只需要"给定 (μ1,μ2)=Log|β| 是否在 amoeba 内/外"的点判定；本文给的正是这种判定，且方向是**严格的外部证书**（lopsided ⇒ 必不在谱内），实现只需多项式乘法（Singular 级），不需要根追踪/延拓。§6 的半代数输出（x ≥ 0 象限内的一组不等式）天然就是 `|β|` 空间的集合描述，可直接用于"GBZ 的 |β| 投影"层面的表述；§4 还能给每个认证点的补集分支 order（有助于分支/洞的归属判断）。
- **障碍**：①**系数必须精确**（`Q[√−1]`）——非厄米模型里的 E、跃迁参数是浮点/超越数，需要先有理化或做区间/高精度版证书，否则 lopsided 不等式不再可靠；②它只给"在外面"，要定位 GBZ 曲线/central hole 边界仍需在网格上二分并把 ε 压小，而 ε↓ ⇒ k↑ ⇒ CycRes 项数/系数指数膨胀（Table 1 已示：二变量 4 项多项式在 r=64 时 >10⁸¹¹ 量级系数），所以**实际可用的 ε 很有限**（推断）；③amoeba 内部点该方法不判定，必须与 Ronkin/winding 型**内部**判据（如本工作区 `pygbz2d/amoeba.py` 的 a2 平均绕数 + μ₂/μ₁ 二分）互补使用——两条路线互补而非替代（推断）；④§7.4 报告的不单调收敛意味着不能简单"加层数就更好"，需要逐点比较而非单调外推（这是原文的实测告诫）。
