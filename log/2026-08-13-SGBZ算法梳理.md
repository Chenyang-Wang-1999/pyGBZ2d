# SGBZ 算法梳理

**最后更新**: 2026-08-13（μ₂_mid 框架重写后）

> 本文档取代 `2026-08-05-SGBZ算法梳理.md`。旧版把交点探测当成独立的 pairwise 流程，繁琐且在多 index 跳变处失效。引入精确求解的 μ₂_mid 后，SGBZ 的交点探测与 amoeba 统一——唯一区别是 mu2 从常数变成曲线。详见各节。

原来的算法（见 `brute_force_SGBZ`）以 `continuation.ZeroManager` 为根求解器后端。模块结构：

- `continuum.py`: 连续模相等探测（§1）
- `crossings.py`: 交点探测与求解（§2）
- `winding.py`: 拓扑荷与平均绕数计算（§3）
- `plateau.py`: 零平台检测
- `sgbz_solver.py`: 顶层求解器

先梳理整体思路：按照文章（`sn-main.tex`, `sn-supp.tex`），SGBZ 求解是通过给定参考能量 E_ref，求解 E_ref 对应的 SGBZ subset 实现的。
SGBZ subset 的求解方式：二分 mu1（mu1 = ln|beta1|），对每个 mu1 求平均主轴绕数 W(E_ref, mu1)。给定 E_ref 时 W 关于 mu1 单调递增。依定义，SGBZ subset 在 W - mu1 曲线穿过横轴的位置求解。

对给定 (E_ref, mu1)，让 theta1 遍历 [0, 2π]，求解关于 beta2 的多项式 `char_poly(E_ref, beta1, beta2) == 0`，得到 M + N 个根（-M 与 N 是 beta2 的最小负幂次和最大正幂次）。按模长排序，subset 由满足 `|beta2_M| == |beta2_{M+1}|` 的点组成（每个点是有序对 (beta1, beta2)）。对应 python 下标是 M-1 与 M（0-based）。

W 的变化与 subset 结构有关：subset 为空集时 W 随 mu1 不变；subset 为 0 维点时 W 连续变化；subset 含 1 维线时 W 跳变。

W 的定义与性质见 `sn-supp.tex`。求解需充分利用绕数的拓扑等价性——数值绕数依赖环绕路径质量，路径离零点太近则噪声导致 ±1 误差。故应选**尽可能少**的环绕路径，用零点拓扑荷辅助推其他区域绕数。绕数在穿过零点的路径上无定义，只有零点在 theta2 轴投影是零测集时平均绕数才有定义，所以只在 subset 只含 0 维点时计算绕数。对 1 维线不计算平均绕数，而是扰动 mu1 数值判断 W 左右极限是否异号，以此判断 W - mu1 曲线是否在此穿过横轴。

由于"探测 1 维线 + 0 维点"与"只探测 0 维点"在 μ₂_mid 框架下复杂度相当（见 §1、§2.4），故最终求解阶段不分简繁两版。**唯一保留简化版的地方**是二分阶段的布尔的 early-return 闸门（§1 末），它只需知道"有无 LineSubset"而不解边界。

## 1. 连续模相等探测

`continuation.ZeroManager` 给出所有根关于 theta1 的函数，且保证每根关于 theta1 连续变化（不发生根间跳变）。复解析性保证：两曲线在某开集上保持模相等则全程保持，直至端点转过 2π 重合或遇重根。对应到 ZeroManager：`SegmentData.tracked_roots` 中两列只要一段模相等，整列都应保持相等（用类似 `brute_force_amoeba` 的投票/整段判据判断）。

注意：SGBZ subset 中的 LineSubset（1 维线）**不一定**充满 tracked_roots 的一整列——根的模长排序受其他列变化影响，模相等的两根可能不再是排序位 M-1 与 M。故连续模探测要覆盖**所有**同模列对（含 (M-2,M-1)/(M-1,M)/(M,M+1) 三组排序对），不只边界对——因为 (M-2,M-1)/(M,M+1) 的 continuum 同样使 j_lo/j_hi 在同模列间任意跳（abs_argsort 不稳定），影响 μ₂_mid 构建。

### 统一探测器（代表元 + 整段同模）

不分简繁两套检测逻辑，由一个探测器统一处理：对每段，所有列对 (j,k) 整段 `|ln|β_j| − ln|β_k||` 最大值 < tie_tol → 同模，传递闭包（BFS）合并成 clusters。整段同模 = continuum（real-analyticity），偶然同模（孤立点）不会整段 < tol，自动排除。

构建 per-segment `ItemView`：把 K 列抽象成 n_items 个代表元。cluster 内取一个代表列（重数 = cluster 大小），非 cluster 列各自一个代表元（重数 1）。`sort_to_item[i, p]` = 排序位 p 对应的 item 索引（item 按模升序，重复 mult 次）——即"M 和 M-1 对应到 cluster index 重新排序"。`j_lo = sort_to_item[:, M-1]`、`j_hi = sort_to_item[:, M]`；`j_lo == j_hi` ⟺ M-1、M 落入同一 continuum item ⟺ 1D subset（`|β_M|=|β_{M+1}|` 恒成立）。

原版（无 continuum）是特例：`n_items = K, mult = 1, sort_to_item = abs_argsort`。

### continuum 判定并入 μ₂_mid 构建（取代独立的布尔闸门）

二分阶段（`sgbz_solver._evaluate_winding`，详见 §6.3）每个 μ₁ 探针完整构建 μ₂_mid（环路积分本就需要它作路径，而根求解是大头、构建开销可忽略）。continuum 在构建中 inline 读出：`j_lo == j_hi` 区间即 1D subset（`|β_M|=|β_{M+1}|` 恒成立）。检出 continuum 即转左右极限、跳过 W 计算。

故不再需要独立的 `detect_continuum_simple` 布尔闸门——它原先的"只问有无、不解边界"语义被 μ₂_mid 构建自然吸收：构建既给边界（精确断点）又给 continuum 判定。

**安全约束**：构建若漏 continuum 会按 0D 算 W，得出错误绕数，二分跑偏。故 continuum 判据**不能有假阴性**，须用整段 frac 判据（`mean(|la − μ₂_mid| < tol) > frac`，即 amoeba 的 `_continuum_mask` 套到边界对），而非旧版"两个连续点 M-1/M 模等+导数等"的两点浮点判定（亚网格 continuum 会漏）。**省的是边界求解，不是判据的可靠性。**

> 一句话：简/繁分裂的两套检测算法不再存在——一个 μ₂_mid 构建同时给出 continuum 判定与精确边界。

## 2. 交点探测与求解

### 2.0 核心思路：μ₂_mid 是一等公民的分段光滑对象

`μ₂_mid(θ₁) = (ln|β_{j_lo}| + ln|β_{j_hi}|) / 2`，分段光滑；断点 = j_lo/j_hi 变化处。构建为一等数据对象，带：
- `values`：解析值（来自 `item_logabs`）；
- `derivs`：解析一阶导数 `d(μ₂_mid)/dθ₁ = (Re(V_{j_lo}) + Re(V_{j_hi}))/2`（来自 `item_tang_re`，光滑域内成立）；
- 断点处 `deriv_left / deriv_right`（严格左右极限，用 θ* 行 + 左右段 item 索引精确算）。

断点按触发排序对分三类：`M-2_M-1`（j_lo 换第三列）、`M-1_M`（j_lo/j_hi 互换 = PMGBZ 边界 crossing，`is_pmgbz=True`）、`M_M+1`（j_hi 换第三列）。`M-1_M` swap 同 {a,b} 集 ⟹ 导数严格连续；内部断点 {a,b} 集改变 ⟹ 导数真跳变。

μ₂_mid 精确求解后，**交点探测 = 逐列根曲线与 μ₂_mid 比较求交**，与 amoeba 的交点探测统一。这是本版相对旧版的最大改动。

### 2.1 与 amoeba 的统一：mu2 从常数变曲线

amoeba 的 `extract_amoeba_subsets` 结构：continuum mask → 逐列 `d = la - mu2` 符号变化 → hits → 边界去重 → 物化。SGBZ 沿用其结构，**唯一区别是 mu2 从标量变为 `mu2_mid_arr[s]`（每 segment 一个数组）**：

| amoeba（mu2 常数） | SGBZ（μ₂_mid 曲线） | 动什么 |
|---|---|---|
| `d = la[:, other] - mu2` | `d = la[:, other] - mu2_mid_arr[s]` | 减数组而非标量 |
| continuum mask：`|la - mu2| < tol` 整段 | `|la - mu2_mid_arr| < tol` 整段 | 同上——命中即 1D SGBZ 线 |
| 精修：`_find_exact_crossing` 2D fsolve（mu2 固定，解 (t1,t2)） | 1D bracketing：`g(θ)=ln|β_j(θ)|−μ₂_mid(θ)=0` | 结构不同，见 §2.3 |

### 2.2 为什么逐列检查不会出假阳性

沿用 amoeba 结构存在一个看似的隐患：amoeba 中**每根** track 穿过 mu2 都是合法子集点（amoeba 子集 = 网格线上所有零点）；SGBZ 的合法点只有**边界对** |β_{M-1}|=|β_M|，则检查所有列是否混入非边界列穿过 μ₂_mid 的假阳性？

答案是**不会**，这恰是"只差 mu2 变曲线"能成立的数学原因：

- μ₂_mid = (ln|β_{(M-1)}| + ln|β_{(M)}|)/2 落在排序后**相邻**的 (M-1)、M 两个模长之间——这个 gap 里**没有别的 track**。
- 一根 track 要穿过 μ₂_mid（从 gap 下方到上方），必须在穿过瞬间被 gap 夹住、即成为边界列；而边界列模长等于 μ₂_mid ⟺ |β_{(M-1)}|=|β_{(M)}| ⟺ gap 闭合 ⟺ SGBZ 点。

故"track j 穿过 μ₂_mid" ⟺ "边界 gap 在 j 上闭合" ⟺ SGBZ 点。逐列检查恰等价于 SGBZ 点集，与 amoeba 同样无冗余——多 index 跳变（如 M+3→M-2）亦被检出：该 track 必然穿过 μ₂_mid 一次而被命中。这正是 sort-change 检测的盲区（单对 bracket 假设一区间一次交叉，多跳变时 `v0·v1>0` 丢弃事件）由逐列法弥补之处。

### 2.3 精修：cubic Hermite bracketing 迭代（替代 Newton）

对每个可疑区间（逐列 `d[j] = ln|β_j| − μ₂_mid` 符号变化），**该 track j 的模长曲线直接与 μ₂_mid 求交**——不再两两代数曲线求交。bracket `[θ_lo, θ_hi]`，`g(θ) = ln|β_j(θ)| − μ₂_mid(θ)`：

1. 两端 value：`g(θ_lo) = ln|β_j(θ_lo)| − μ₂_mid(θ_lo)`，`g(θ_hi)` 同理（μ₂_mid 取其一等对象的精确值，不是插值近似）；
2. 两端解析导数：`g'(θ) = Re(V_j(θ)) − dμ₂_mid/dθ₁(θ)`——track 侧用其 Re 切线 `Re(V_j)`，μ₂_mid 侧用其解析导数 `(Re(V_{j_lo}) + Re(V_{j_hi}))/2`（光滑域内成立；断点处取左右极限）。**端点导数奇异时（MR 分支点 `V_j→∞`、tangents=None 或 `g'` 非 finite）退化为线性插值**：用两端 value 连线作预测，放弃该端的解析导数。线性预测精度低，但只作为 bracketing 的初始猜测，后续 `insert_solution` 取真值收紧 bracket，仍能收敛（只是阶数从 cubic 降到 linear）。墙（§2.4）的目的之一就是把 bracket 端点推到 MR/tangency 之外，使退化尽量不触发。
3. 由两端 (value, g') 建 cubic Hermite → `np.roots` 预测 θ_pred → `insert_solution` 取真值 g_pred 与真值导数；
4. 用**导数符号（走向）+ g_pred 符号**定 θ_pred 在根的哪一侧，收紧 bracket，重建 cubic。收敛于 bracket 宽度 < xtol。

**拓扑荷附带可得**：§3.1 的常点拓扑荷 = `sign(g')`。因 track j 在交点处必为边界列（§2.2），此时 `g = ln|β_j| − (ln|β_{j_lo}|+ln|β_{j_hi}|)/2 = (ln|β_{j_lo}| − ln|β_{j_hi}|)/2 = gap/2`，故 `sign(g') = sign(gap 导数)`——精修时已算，无需单独的分类 pass。

**为什么不用 Newton**：Newton `θ − g/g'` 单点商在切触处 `g'≈0` 跨步巨大、在重根分支点 `g'→∞` 步长退化，都不可靠。bracket 只在墙外（远离 MR）、MR-free 端点用 g'，端点 finite，且导数符号判据不依赖 g' 大小，bracketing 单调。**为什么不用纯变号检查**：g_pred 与两端同号时（cubic 近似误差）变号检查失效、best_pred 可能死循环；导数符号不依赖两端符号，直接由走向定侧。

amoeba 的 2D fsolve（mu2 当固定参数解 (t1,t2)）不直接搬——SGBZ 的点本身就在 track 上（边界对交叉处），是 `g(θ₁)=0` 的一维求根，用 track 解析切线 + μ₂_mid 解析导数即可。

### 2.4 墙、MR 断点、跨 segment

- **墙（walls）**：在近并列行（三组排序对近相等或 MR 行）左右 `wall_frac·grid` 处插点，让 sort-change 检测只在墙外跑；墙点提供干净的 finite-tangent 端点，使 bracket 的端点 f' 可靠。
- **亚网格/切触兜底（保留 §2.1 判据 2）**：gap 在一区间内闭合又张开时端点符号不变（`d` 积 > 0）会漏，依赖"两端 |d| 均小于阈值"检出 near-miss 再 `insert_solution` 加密网格。这不是去重，是亚网格/切触检测。多 index 跳变若集中在单一区间内，亦依赖此判据。
- **MR 断点**：MR 行 cluster snapping 使多根精确等模，abs_argsort 完全不稳定。MR 断点直接从 `multiple_roots.cluster_indices`（覆盖 M-1 或 M 的 cluster）取，跳过 sort-change 检测；导数奇异（重根分支点 `dβ/dθ` 发散）→ `deriv_left = deriv_right = inf`，下游插值特殊处理。
- **continuum**：`detect_continuum_full`（生产 `continuum.py`）目前只由 M-1/M 边界播种候选 run，**应扩展为整段所有列对**（§1 统一探测器）。完整版 = 用代表元 ItemView，continuum = 整段 `|la − μ₂_mid| < tol` 的 track，`j_lo==j_hi` inline 标 1D 线。
- **跨 segment**：左闭右开区间保证跨 segment 边界无重复；ZeroManager 保证前一 segment 右端点精确对应后一 segment 左端点（浮点 ==）。

### 2.5 去重（§2.3 旧版的 NotImplementedError 删除）

旧版 pairwise 写法（`f = ln|β_a| − ln|β_b|`）下，同一 SGBZ 点可能被 (A,B)、(A,C) 等多列对同时命中，需要成对去重——故有 `raise NotImplementedError` 占位。

逐列 vs μ₂_mid 写法下此问题不出现：interior crossing 身份键 = `(seg, interval, track j)`，逐列逐区间天然唯一；不同 track 同一 θ₁ 的 β₂ 不同，也不撞。去重只剩 amoeba 那两条（继承即可）：
- **Rule 1**：crossing 落在 continuum LineSubset 端点 `snap_tol` 内、且 β₂ 与该端点根匹配 → 丢（continuum/MR 边界，非离散零点）。
- **Rule 2**：`d==0` 精确触碰按 `_zero_identity_key` 去重。

## 3. 拓扑荷与主轴平均绕数计算

拓扑荷参考 `sn-supp.tex`。它只对主轴平均绕数有用，且只对 0D 点集良定义。数值上 = theta2 从左到右跨过零点时环路绕数的变化值。

### 3.1 拓扑荷分类（常点冗余，重根/切触须明示）

零点拓扑荷只对 0D 点集良定义，数值上 = theta2 从左到右跨过该零点时环路绕数的变化值。分三类：

- **常点**（横截穿过 μ₂_mid）：拓扑荷 ±1，由穿过走向定（track 由下向上穿过 μ₂_mid → +1，反之 −1）。新框架下 = `sign(g')`（§2.3 精修时已算，`g' = Re(V_j) − dμ₂_mid/dθ₁`），无需单独的方向判定 pass。生产 `_classify_charge` 的 `charge = 1 if f_prime>0 else -1` 即此。
- **切触**（track 与 μ₂_mid 相切不穿过）：拓扑荷 = **0**——切触点拓扑结构未改变（±1 零点成对产生/湮灭，净变化 0）。但数值上"真切触"与"近切触的横截对"难区分，实现上保守当 hard boundary。
- **重根**（MR 分支点）：拓扑荷**未知**——需环绕重根的小环路计算，而数值误差太大无法可靠求得。实现上以 `charge = 0` 占位（表示"不传播"）当 hard boundary，但**物理值非 0，是未知**。

> 即：实现里"重根/切触 → charge 0、hard boundary"是统一的工程处理，但物理上重根是"未知"、切触才是"0"。算法行为不受影响（都当 hard，左右各算一次绕数），但此处写清以免误解。

### 3.2 拓扑荷传播策略（保留）

平均绕数 = 一系列环路绕数的均值。环路定义：保持 mu1 和 theta2 不变，theta1 环绕 2π，同时 mu2 = μ₂_mid(θ₁)（分段光滑）。

μ₂_mid 构建不计算 W 本身，W 仍需至少每 region 一次环路绕数。常点拓扑荷 ±1 用来把一个 region 算出的 w0 推到邻区（C 区 w0 → D 区 w0−1 → A 区 w0 → B 区 w0+1），最小化环路绕数计算次数。重根（拓扑荷未知）须当 hard boundary、左右各算一次；切触物理拓扑荷为 0（本可不划区域、按 w0 推过），但数值上切触 vs 近切触横截对难区分，实现上保守当 hard 同样左右各算一次。

环路路径 μ₂ = μ₂_mid(θ₁) 现在是精确分段光滑对象（带解析导数 + 断点左右导数），旧版"全局三次样条不安全→改折线"的权衡不再适用——既非插值近似也非折线近似，是精确曲线。实际绕数计算仍采样之，但路径定义精确。

为鲁棒性，在整个 theta2 区间取多条曲线，选离零点最远的那条算环路绕数，避免 ±1 数值误差。

## 4. 实现细节与代码审查要点

### 4.1 collect-then-refine 模式

逐列检测先收集所有可疑区间（hits），再统一精修。精修的 `insert_solution` 会修改 `SegmentData.tracked_roots`，若边遍历边精修，后续区间读取被改数据。新框架的 cubic Hermite bracketing 每次迭代自含（re-locate + 重建 cubic），refinement 内部快照压力小于旧版 Newton，但 collect-then-refine 仍保留。

### 4.2 平台检测的聚类前检查

`plateau.py` 的 `_check_pmgbz_points_clustered` 用 **(θ₁, θ₂) 环面欧氏距离**判断点是否聚集：

```python
d1 = _circ_dist(t1_i, t1_j)
d2 = _circ_dist(t2_i, t2_j)
d = sqrt(d1² + d2²)  # 欧氏距离
if d < tol_rad:
    has_neighbor = True
```

**必须同时考虑 θ₁ 和 θ₂**，不能只看 θ₁：同一 θ₁ 可有多个不同 β₂（简并对），只看 θ₁ 会误判为"聚集"。例：gain-loss Haldane 在 E=0.5 有 6 点分 3 对简并对，环面上最小距离约 33°，远大于容差 3.6°，正确判为"非聚集"。

此检查**不受 μ₂_mid 框架影响**，仍需保留。

### 4.3 二分过程中的 continuum 处理

`sgbz_solver.py` 的 `handle_continuum` 闭包注意变量作用域：bracket expansion 阶段调用时 `mu1_high`、`w_high` 可能未赋值，函数开头初始化为 `None`。

### 4.4 bisection 收敛条件

`w_mid` 为 `None`（continuum 非边界）时不检查收敛：

```python
if w_mid is None:
    f_mid = proxy_w  # 左极限作代理
else:
    f_mid = w_mid
    if abs(f_mid) <= zero_tol or (mu1_high - mu1_low) < xtol:
        return ...
```

continuum 点 W 无定义，用代理值判收敛会混淆"左极限为零"与"W 为零"。

### 6.1 多 index 跳变

### 6.2 MR 左右导数
已解决。MR 断点 `dβ/dθ` 发散、解析导数不可用，环路在该段用线性插值构造 `mu2(t)`（与 §2.3 端点导数奇异退化为线性插值一致），下游 `quad` 积分正常进行，无需特殊处理。

### 6.3 二分阶段完整构建 μ₂_mid
`solve_SGBZ_for_E` 每个 μ₁ 探针完整构建 μ₂_mid（不再只用布尔闸门）。理由：W 的环路积分本就需要 μ₂_mid 作路径，构建不可避免；而根求解（`ZeroManager.run`）是开销大头，μ₂_mid 构建相对可忽略。continuum 在构建中 inline 读出（`j_lo==j_hi` 区间，即 1D subset），无需单独的 `detect_continuum_simple` 闸门——检出即转左右极限、跳过 W 计算。

> 这修订了 §1 末的"布尔闸门"：闸门不再是独立检测函数，continuum 判定并入 μ₂_mid 构建。§1 末的"假阴性零容忍"约束自然满足——完整构建若漏 continuum 会直接错算 W，二分即跑偏，故构建本身必须可靠（§1 整段同模判据保证）。

### 6.4 W 平均值：沿用老代码的分段积分
μ₂_mid 分段光滑，环路绕数直接复用 `winding.py`（HEAD 提交）的 `WindingFun` + `get_winding_number`：

- **被积函数**：`WindingFun` 计算 `Im[f'/f]`，`f = char_poly(E, β₁, β₂)`，`df/dθ₁ = ∂f/∂β₁ · dβ₁/dθ₁ + ∂f/∂β₂ · dβ₂/dθ₁`。
- **loop_fun**（`t = θ₁`，`θ₂` 固定）：`β₁ = exp(μ₁ + iθ₁)`，`dβ₁/dθ₁ = iβ₁`；`β₂ = exp(μ₂_mid(θ₁) + iθ₂)`，`dβ₂/dθ₁ = β₂ · dμ₂_mid/dθ₁`（用 μ₂_mid 的解析导数）。
- **段内插值**：`μ₂_mid(t)` 及其导数在每段光滑区间内由断点值 + 解析导数做 cubic Hermite 插值得连续表示（MR 段线性，见 6.2），供 `quad` 自适应求值。
- **分段积分**：`get_winding_number` 的积分区间由原等分 `N_seg` 改为按 μ₂_mid 断点切分，每段光滑区间单独 `quad`，求和除 `2π`。
- **W = 平均值**：对多个 `θ₂` 各算一次环路绕数取均值；用 §3.2 的拓扑荷传播策略最小化 `θ₂` 计算次数。

老代码曾因"全局三次样条跨断点不安全"被质疑——现在 μ₂_mid 是精确分段光滑、断点已知，样条/Hermite 限制在段内即安全，故沿用。
